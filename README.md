# Media & Series Streaming Platform

A modern full-stack web application for streaming videos and series, featuring secure user management and optimized media storage.

## Key Features
- **Media Catalog:** Browse and stream dynamic series and video content.
- **Authentication & Backend:** User account creation, session management, and relational data handling via Supabase.
- **Optimized Media Delivery:** Integrated cloud video delivery architecture (Bunny.net / Cloudflare Stream) for continuous streaming.
- **Responsive UI:** Fast, reactive user interface optimized for desktop and mobile devices.

## Tech Stack
- **Framework:** Next.js (React)
- **Database & Auth:** Supabase
- **Media Hosting:** Bunny.net / Cloudflare Stream
- **Styling:** Tailwind CSS
